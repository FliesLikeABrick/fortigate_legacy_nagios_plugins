# fortigate_legacy_nagios_plugins
Archiving miscellaneous nagios plugins from elsewhere that are being lost to time/bitrot

Collecting (at least 2 initial) Fortigate-related check scripts that are no longer available online

## check_fortigate_status
check_fortigate_status.pl is described here but was never directly uploaded:
https://exchange.nagios.org/directory/plugins/hardware/network-gear/fortinet/check-fortigate-status/details/

The link provided is to http://www.interwebplus.com/blog/index.php?post=nagios-monitor-fortigate-firewalls which is no longer online.
The file check_fortigate_status.pl was retrieved from the plaintext of an old forum thread in archive.org at this link (alive via archive.org as of September 2026)
https://web.archive.org/web/20120304103705/http://www.interwebplus.com/blog/index.php?post=nagios-monitor-fortigate-firewalls

## check_fortigate_cpu
check_fortigate_cpu.pl appears to be the original upstream/inspiration for check_fortigate_status, it was perhaps originally hosted at 
https://exchange.nagios.org/directory/plugins/hardware/network-gear/fortinet/check-fortigate-cpu-load/details/
however that listing has no files nor download links.

The original script was found by following a link from the same check_fortigate_status forum thread linked above, it links to 
https://web.archive.org/web/20120304103705/http://exchange.nagios.org/directory/Plugins/Hardware/Network-Gear/Fortinet/Check-Fortigate-CPU-load/details
which is an old version of the nagios exchange listing which *does* have the file attached.
The direct download link (still working from archive.org as of September 2026) is https://web.archive.org/web/20130623082003/http://exchange.nagios.org/components/com_mtree/attachment.php?link_id=2700&cf_id=24
